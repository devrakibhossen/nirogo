# 🏥 Nirogo

> Online pharmacy platform for smart medication management.

Nirogo (Bengali: রোগমুক্ত / disease-free) is a full-stack 
e-pharmacy platform .

## 🚧 Status
Project in active development — Week 1 of 12

## 🎯 Features (planned)
- [ ] User authentication (JWT)
- [ ] Medicine catalog with search & filter
- [ ] Cart & order management
- [ ] Prescription upload
- [ ] Admin/pharmacist panel

## 🛠️ Tech Stack
- **Backend:** FastAPI, PostgreSQL, SQLAlchemy
- **Frontend:** React (coming soon)
